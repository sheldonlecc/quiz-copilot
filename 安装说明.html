答题助手 QuizCopilot

自动读取网页题目，AI 给出答案和解析，可选一键勾选 / 填入；选中一段话还能让 AI 讲明白

它做什么

在答题页面上按一下，插件会把页面里的题干和 A/B/C/D 选项抽出来，一次性发给模型，答案和解析直接显示在右侧面板里。不用再复制粘贴、来回切窗口。

读取页面题目
STEP 2

STEP 4
你确认后勾选提交

1加载插件（一次性）

Edge 用户看这里。地址是 edge://extensions，不是 chrome://extensions —— 后者在 Edge 里打不开或跳空白页，这是最容易卡住的一步。

Microsoft Edge：

  1. 地址栏输入 edge://extensions 回车
  2. 打开左侧栏的「开发人员模式」开关
  3. 点页面上的 加载解压缩的扩展
  4. 选中下面这个文件夹
  5. 回到工具栏，点拼图图标，把「答题助手」固定出来

Google Chrome：

  1. 地址栏输入 chrome://extensions 回车
  2. 打开右上角的「开发者模式」开关
  3. 点 加载已解压的扩展程序，选中下面这个文件夹
（解压目录）\quiz-copilot

装好后工具栏会出现一个蓝色的小机器人图标（白色脑袋、绿天线那颗）。

2怎么确认更新已经生效

面板标题右边有一个小徽标，写着当前版本号，例如 v1.19.2。这个数字是插件运行时直接读自己 manifest 得来的，不会骗人。

如果你看到的还是旧版本号，或者工具栏里没有「诊断」按钮，说明页面里跑的还是旧代码，按这个顺序操作：

  1. 地址栏输入 edge://extensions（Chrome 用 chrome://extensions）
  2. 找到「答题助手」卡片，点上面的刷新图标 ↻（Edge 中文版可能显示为「重新加载」）
  3. 回到答题页面，按 F5 刷新
  4. 再打开面板，确认徽标上的版本号变了
只按 F5 是不够的。扩展本身没有重新加载，页面里注入的还是旧脚本。必须先刷扩展，再刷页面。这是「明明改好了却还是老样子」最常见的原因。

刷新图标藏在卡片上，鼠标移上去才会明显显示。实在找不到，就把这张卡片删掉，重新「加载解压缩的扩展」一次。

3填 API Key

点工具栏的小机器人图标，在弹出的设置页里操作：

  1. 服务商选 DeepSeek（已经预填好地址和模型，不用改）
  2. 把 API Key 粘进去
  3. 点 测试连接，看到「连接正常」就说明通了
  4. 点 保存

还没有 Key？去 platform.deepseek.com 注册，创建一个就行。充 10 块钱能用很久——答一份 20 题的卷子大约几分钱。

想用别的模型？设置页里的服务商下拉框已经内置了通义千问、Kimi、智谱、硅基流动、OpenAI 的地址。选 自定义 的话，任何 OpenAI 兼容接口（Base URL + 模型名）都能接。

支持哪些题

题型怎么认出来的能否自动填
单选radio 选项能
多选checkbox 选项能（会顺手取消多勾的）
判断选项是「正确/错误」「对/错」「是/否」能
填空文本框、数字框，或题干里的 ____ 横线能（一题多空按顺序填）
表格 / 矩阵一张表，每格一个输入框（问卷星的矩阵题）能，按行从左到右填
匹配左右两列，右列是下拉框能，但有条件 —— 见下方说明
论述 / 简答大编辑框（textarea / contenteditable / 同源 iframe），题干里有「论述、简答、谈谈、不少于 N 字」这类词能，整篇写入
编程题页面里有 Monaco / CodeMirror / Ace 代码编辑器，整页当成一道题读能，写进编辑器（平台不认时给「复制代码」）
匹配题的限制：插件把左列每一项的文字 / 图片文件名 / alt 属性读出来交给模型。 如果左列是纯图标且图片既没有 alt、文件名也没意义（比如 image1.png）， 模型看不见图标长什么样，就只能瞎猜 —— 这是文字模型的硬限制，不是 bug。
好在很多题库的图片文件名是可读的（linkedin.png、twitter-bird.png），这种能推出来。

填空题如果一题有多个空，模型会按横线出现的先后顺序作答，几个答案之间用 ||| 隔开，插件再逐个填进去。多空的卡片顶部会显示「2 空」这样的标记，展开能看到每个空的具体答案。

表格题（一张表、每格一个输入框，问卷星的矩阵题就是这种）会按「第 1 行从左到右 → 第 2 行……」的顺序填。卡片上会写「表格」并列出每行的标签。

论述 / 简答题：题干里出现「论述、简答、案例分析、谈谈、不少于 N 字」这类词，又配了一个大的编辑区，就按论述题处理。 插件会把字数要求（比如「700-1000字」）一并交给模型，让它写足、分段；如果是「二选一」，只写其中一题并在开头注明选了哪题。 写进页面时是整段写入，不会因为答案里有分号就被切开。

论述题写不进去怎么办？学习通作业页的编辑器（UEditor 那种 iframe）能直接写，写入后还会把同一段文字补进它隐藏的 textarea，防止编辑器不同步导致交空卷；但有些富文本编辑器只认自己的输入， 脚本改不动。这时面板里会显示字数、要求和「复制全文」按钮 —— 点一下复制，粘进编辑器即可。
跨域 iframe 里的编辑器浏览器不允许脚本访问，同样只能走复制粘贴。
个人信息题不会被瞎填。作息时间、收入、身份证号这类只有你自己知道的数据，模型给不出答案时 answer 会是空的；如果它一边说「无具体信息」一边给了个数字，插件也会把这个数字丢掉，不会替你填进页面。
计算题会做一次「答案 / 解析对账」。模型偶尔会这样：解析里老老实实算到 ≈1.41， answer 却写成 1.00。插件会把解析里最后一个「= / ≈」后面的数字抓出来跟答案比， 明显对不上就在卡片上标黄，写「解析算出 1.41，答案却是 1.00」，旁边给一个 用 1.41 按钮， 点一下改答案并重新填入这一题。提示词里也加了「先算完再把结果写进 answer」的要求，但模型不保证每次都听。

搜索框、登录框、姓名/学号/邮箱这类个人信息字段会被主动跳过，不会被当成填空题乱填。

编程题（LeetCode / 牛客 / 洛谷这类判题页）现在能做了。识别到代码编辑器时，插件把整页当成一道题： 题面、示例、约束，加上编辑器里已有的代码模板，一起发给模型，先给「思路 + 复杂度」，再给完整代码。 面板上并排两个按钮：写入编辑器（Monaco / CodeMirror / Ace 都能写，写的是编辑器自己的 model，页面那边当普通输入处理） 和 复制代码（永远可用）。语言从模板推断，模板里的函数名、类名、参数不会被改。

编程题只写不跑。代码写进编辑器就停手，不点「运行」也不点「提交」——判题结果插件拿不到，也不该替你做决定。 代码对不对，请自己跑一遍示例再交。个别平台把编辑器包在跨域 iframe 里，这种写不进去，用「复制代码」手动粘。
写错了能还原。写入前会先把编辑器里的原件记下来，卡片上出现「还原」按钮，点一下退回上一步。 语言不用手动切：在页面上把语言换成 Python，编辑器会跟着换成 Python 模板，插件照模板推断，写出来就是 Python。

高校常用的 Moodle 一类系统，选项的 name 是逐个独立的（q4:1_choice0、q4:1_choice1…），插件会按「就近容器」把它们并回同一题，不会拆成一堆单选题。

4开始用

  1. 打开答题页面，刷新一次（插件是刚装的，已有标签页里还没生效）
  2. 右下角会出现一个小机器人
  3. 点它，或者按 Alt + Shift + Q —— 它会自己读题、作答、填进页面
  4. 看完想核对，按 Alt + Q 打开面板，逐题看答案和解析
「自动填」开着的时候，点一下就直接写进页面。填完它会报数字：「已填 6 题」， 有没填上会说「已填 5/6，1 题需手动」。关掉自动填，就只算出答案，弹个气泡让你点开看。

小机器人

右下角那个小机器人是常驻的，正常看网页时也在。它会眨眼、左右张望，还会换表情： 开心时眼睛眯成两道半圆、委屈时外眼角垂下来、不高兴时内眼角压下来；没人理 50 秒就打瞌睡，头上会飘起 zzz。

所有小动作的收尾都带惯性：摸头松手后身体摇摆幅度递减、爱心边飘边淡、腮红慢慢褪；歪头回正会转过头一点点再摆回来； 蜘蛛网散掉时带一下余震；连状态色和眼睛形状都是渐变过去的，不会「一松手动画就没了」。

干活时的手势：读题的时候头顶翻三页小纸片；每填完一页，头顶弹一个数字球（写着填了几道）， 同时一张小卡片朝页面方向飞走；收工时会盖个小红章；要是答案和解析对不上，它会歪着头冒一个问号。

它自己会做的事：闲着 30 秒偷看一眼头顶的计时牌；光标从它身上移开 1.5 秒，会左右找人； 页面滚太快会被带着后仰一下（1.5 秒最多一次）；切到别的标签页再回来，伸个懒腰——要是已经睡着了，就先醒再伸。

换装也会动：换帽子时帽子晚 80 毫秒才落下、身体先跳一下；摸头时猫耳/兔耳跟着抖两下；戴着围巾闲着时围巾会轻轻飘。

它自己会做的事：闲着 7～13 秒会像史莱姆那样蹦一小段（之后每隔 12～26 秒一次，一次挪 100 多像素并记住新位置）； 鼠标靠近它、正在算题、或者已经睡着的时候不会乱跑。

没人理 42 秒会先打个哈欠，50 秒打瞌睡，睡着后鼠标靠近会先惊一下再醒，醒来重新开始蹦。

一直没人理的话，睡着之后 40 秒（也就是闲置 90 秒）它脑袋右上角会结出一张蜘蛛网、网上挂着只小蜘蛛， 这时候它已经睡熟了，不会说话；你鼠标一靠近，它先「！」一下醒过来，顺手把网抖掉，说一句「呼，清爽了」。 睡着也会结网——睡到长网才是「真的很久没人理」。抖掉之后重新计时，再没人理过 90 秒又会结一张。

五种状态：

待机蓝色，眨眼张望、随机换表情；鼠标移上去会笑一下
思考眼睛脉动、天线闪，气泡写「正在读题 / 读到 N 题作答中」
全部填好变绿，对勾一笔画出来，气泡写「已填 N 题」
有几题没填上琥珀色 + 对勾，气泡写「已填 5/6，1 题需手动」

嫌它占地方？设置页关掉「页面右下角显示小机器人」，快捷键照样能用。 系统开了「减少动态效果」时，所有小动作会自动停掉，只保留状态变色。

右键菜单、划词解释、番茄钟

单击已经固定给「一键解题」，所以其他功能都放在不冲突的通道上：右键、悬停、选中文字。这样加多少功能都不会把「点一下就解题」弄坏。

右键小机器人会弹出菜单。菜单只放「马上要做的事」，只在两处有开关， 其余的都挪进了各自的窗口和设置页；开关类点完菜单不会关，可以连着改。

番茄窗：点「番茄钟」打开，占右上角，和答题面板同一个位置—— 开一个会自动关另一个，不会两个窗口叠在一起。两个窗口都能拖标题栏移动，松手后位置会被记住。里面三个页签：

  • 专注：中间是环形倒计时，上面选这一轮做哪个任务，下面选时长（15/25/45/60 或自己填 1～180），点「开始专注」。休息单独一个按钮。
  • 任务：输入任务名、选分类（学习 / 工作 / 阅读 / 其他）、回车或点「加」。点任务可以设为当前任务，右侧显示已经攒了几个番茄。
  • 统计：今日 / 本周 / 本月切换；环形图按分类看时间占比，下面是最近 7 天的柱状图。数据存在浏览器本地，换页面不会丢。
中途停下也不会白做。设了 90 分钟、实际只做了 5 分钟就点「停止」，这 5 分钟照样记进统计里—— 只有当这一段不足 1 分钟时才丢弃。不过中断的段只算时长，不算一个番茄，也不会让任务的番茄数 +1； 统计页会单独写一行「另 N 段中断（已计入分钟）」。

换页不会丢。计时状态存在浏览器本地，刷新页面、换标签页、用连续做题翻到下一页， 头顶的倒计时都会自己接上接着走。如果离开期间那一段刚好走完，回来会补记一笔，按完整番茄算。

衣橱：右键机器人 →「衣橱」。上半屏是放大的实时预览，下半屏三组按钮， 点一下立刻穿到右下角那个真身上，关掉窗口也能看到效果。

  • 帽子：棒球帽 / 毛线帽 / 小皇冠 / 学士帽。戴上帽子时头顶的天线会自动收起来，不然帽子上顶着一根铁丝。
  • 耳朵：猫耳 / 兔耳。和帽子不冲突，可以同时戴，耳朵会从帽子后面露出来。
  • 领结：领结 / 围巾，挂在下巴底下。
  • 三组都能选「不戴」，也可以点「随机一套」让它自己搭，或者「全部摘掉」回到出厂状态。

穿戴会记住（存在浏览器同步存储里），刷新、换页、换电脑登录同一个浏览器账号都还在。 配件是挂在脑袋上的，所以会跟着呼吸、歪头、干完活抖一下一起动，不会浮在外面。

连续做题：把「自动翻页」打开，然后点一下机器人，它从当前页开始答， 答完自己找「下一页」翻过去接着答，直到页面上再也找不到下一页为止，然后停在最后一页， 气泡写「全部做完：N 页 / M 题，检查后自己交卷」。

为什么「自动翻页」会顺手把「自动填」也打开：连做的意义就是一路填下去， 如果允许「翻页开、自动填关」，实际跑起来还是会填，等于开关在骗人。所以现在反过来—— 关掉「自动填」会同时把「自动翻页」也关掉，两个开关不会再打架。

  • 绝不点提交。「提交 / 交卷 / Finish attempt / Submit」这类按钮会被明确排除；最后一页如果有「Finish attempt」，它会停下来等你。
  • 整页刷新也不会断。进度存在浏览器本地，新页面加载后 1 秒内自己接上继续做。判断依据是「地址去掉 page 参数后还是同一个页面」， 所以像 Moodle 的 attempt.php?attempt=123&page=2 这种能接上；每一页地址完全不同的站点接不上，但同一页内的局部翻页仍然有效。
  • 随时能停。做的过程中再点一下机器人就停，当前这一页做完就不再往下走。
  • 有上限。默认 30 页（可在菜单或设置页改成 50 / 100），防止死循环；中途读不到题、拿不到答案、翻页没反应，都会立刻停下并在气泡里说明原因。

划词解释：在网页上选中任意一段话（至少 4 个字），选区旁边会冒出一个小按钮「解释这段」， 点它才会真的发请求——不点就不花钱。点下去时机器人会先化成一个小球，滚到那段话旁边，落地变回原样再开始解释， 然后它就停在那段话旁边——不会自己跑回角落，想挪走拖它就行。结果显示在面板最上面的「划词解释」卡片里。

它不是用来答题的，是把这段话讲明白：先一句话说清在讲什么，再拆关键点，遇到术语用类比，英文先给中文意思，控制在 200 字以内。

按钮不出现？输入框里的选区不会触发（避免打字时乱弹）；页面自己拦了选择事件也不触发；跨域 iframe 里的文字同样读不到。

读不到题目？先点「诊断」

面板最右边有一个 诊断 按钮。点一下，它会列出：

  • 页面上有多少个输入框、多少个单选项
  • 哪些输入框被跳过了，以及具体原因（太宽、命中搜索关键词、在登录表单里…）
  • 通过初筛的输入框，被归到了什么题干下面
  • 最终识别出几道题

点「复制全部」把这段内容发我，就能精确定位问题，不用猜。

常见原因，按出现频率排：
0. 你打开的不是测验页。两种常见情况：
· 答卷回顾页（地址带 review.php）：交过卷之后再看，所有答案框都是只读的，页面本身就不给作答入口。要做题请重新进入测验，地址变成 attempt.php 才对。
· 课程活动列表页（地址带 course/view.php）：这里只有「Play Video」「Download…」这类学习任务，旁边的勾选框是完成状态，不是选项。请点进标着 Quiz 的那一项。
1. 题目在 跨域 iframe 里 —— 这种情况下任何扩展都读不到，只能把题目页单独打开，或者用「读取选中文字」。
2. 题目由 Shadow DOM 渲染 —— 同样读不到，用「读取选中文字」。
3. 输入框被我的过滤规则误杀 —— 诊断里会写清楚是哪条规则，告诉我就能放宽。
4. 题目还没渲染出来 —— 翻到那一页再读。

诊断的第一行就是页面类型，直接告诉你当前是答题页还是回看页。

其他可以试的办法

  1. 先让题目显示出来。很多答题页是分页或折叠的，没渲染的 DOM 读不到。翻到题目那一页再读取。
  2. 用「读取选中文字」。鼠标框选题目和选项（一次可以框好几题），再点面板里的这个按钮。这条路径几乎什么页面都能过。
  3. 刷新页面。如果提示「扩展刚被更新」，按 F5 就好。
  4. 填空题要求输入框可见。空位在屏外或被折叠时识别不到，滚到那一题再读取。

Edge 专属的四个坑

现象原因与处理
chrome://extensions 打不开Edge 不支持这个地址，用 edge://extensions。这是最常见的一个。
Alt+Q 没反应和别的扩展或输入法抢了同一个快捷键。去 edge://extensions/shortcuts 改成别的组合，或者直接点页面右下角的悬浮小机器人。

去哪测试

1. 本地测试卷（先跑这个）

和这份说明放在一起的 本地测试卷.html，双击用 Edge 打开即可（它也在分享包里）。里面埋了 6 道题，覆盖单选、多选、判断、单空、多空、Moodle 式独立命名，还特意放了搜索框和「姓名 / 学号」输入框当诱饵。

正确表现：读出 6 道题。如果读出 9 道（把搜索框、姓名框也当成题），或者第 6 题被拆成 4 道，就是分组逻辑出了问题。页面底部有个折叠区，点开是对照答案。

本地文件默认禁止扩展注入，要先到 edge://extensions → 答题助手 → 详细信息，打开「允许访问文件 URL」，再刷新本页。

  4. 在课程里找标着 Quiz 的活动，点进去，再点 Attempt quiz now
  5. 地址栏变成 attempt.php?attempt=… 就对了，这时按 Alt+Q

账号 admin / manager / teacher / student，密码以登录页显示的为准。用 teacher 身份建一道测验、加几种题型，再用 student 身份做，能测到你想要的结构。

3. 考试酷（中文题干，结构完全不同的对照）

分享给别人

这个扩展没有上架应用商店，所以「安装包」就是那个文件夹。三种方式，从省事到正式：

1. 发压缩包（最省事）

  1. 把整个 quiz-copilot 文件夹压缩成 zip 发给对方（不用带 dist 或测试页）
  2. 对方解压到任意目录，里面是两样东西：quiz-copilot 文件夹 + 这份说明页
  3. 让对方双击这份说明页，照着最上面第 1 步，加载解压出来的 quiz-copilot 文件夹

API Key 不能随包发。Key 是跟着账号走的，对方得自己申请一个（第 3 步），也千万别把你的 Key 发出去。

2. 直接发仓库链接

仓库是公开的：github.com/sheldonlecc/quiz-copilot。 把链接发给对方，点右上角 Code → Download ZIP，或者 git clone 下来。解压后同样照最上面第 1 步加载 quiz-copilot 文件夹。

公开仓库默认是只读的。想让某个人能直接推代码，再去 Settings → Collaborators → Add people 加对方用户名； 只是想让他改着玩，让他 Fork 一份即可。

3. 上架应用商店（要当产品做才考虑）

渠道情况
Edge 加载项商店开发者账号免费，微软审核，一般几个工作日
Chrome 应用商店一次性 5 美元注册费，审核更严
上架前想清楚。「自动替人答题」这类用途在商店审核里风险很高，很可能被拒；公开传播也会把「协助作弊」的争议放大。 小范围用，或者把源码给信任的人看，比上架稳妥。

说句实话

这东西适合用在练习卷、开卷测验、公司内部培训考试这类允许查资料的场景——它只是把「查资料」这一步自动化了。

需要本人独立完成的正式考试（资格考试、学历考试、招聘笔试）别用它。那些平台大多有行为检测，被判定作弊的代价远大于省下的那点时间。答案也会错，主观题尤其不可靠，最终核对的责任还是在你。
