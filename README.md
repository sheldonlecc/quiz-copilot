# 答题助手 QuizCopilot

一个跑在浏览器里的答题插件：把网页上的题目读出来，交给大模型作答，再按你选择的时机填回页面。

面向**练习卷、开卷测验、内部培训**这类本来就允许查资料的场景。需要本人独立完成的正式考试请别用。

## 能做什么

- **读题**：单选 / 多选 / 判断 / 填空 / 表格（矩阵）/ 下拉匹配，一页混着也能读
- **作答**：默认接 DeepSeek，任何 OpenAI 协议的接口都能填（Base URL 可改）
- **回填**：自动勾选项、写填空、按行填表格、选下拉；React / Vue 受控组件也能写进去
- **一键**：点右下角小机器人，读题 → 作答 → 填入一气呵成
- **划词解释**：选中网页上任何一段文字（教材、题干、英文段落），旁边冒出「解释这段」，点它让 AI 用中文讲明白——不答题，只讲人话
- **右键菜单**：换皮肤、番茄钟、划词解释开关、自动填开关、隐藏机器人
- **番茄钟**：倒计时一直挂在机器人头顶（mm:ss + 进度条），不用悬停；专注 15/25/45/60 分钟、休息 5/10/15 分钟，右键点一下就开始，剩 5 分钟和 1 分钟各提醒一次，结束会蹦起来喊你
- **小机器人**：常驻右下角的桌宠，会眨眼、张望、换表情；鼠标靠近会盯着你看，可以拖着走（位置会记住，贴边会吸附），甩太快会晕出螺旋眼（松手后惯性转完再闭眼 ><，摇晃幅度一下比一下小、停住一下才恢复），双击会蹦一下、连点三下只会不高兴不会解题，打瞌睡时头顶飘 zzz
- **动作都有惯性**：摸头松手后不是立刻换脸——摇摆幅度递减、爱心边飘边淡、腮红慢慢褪；歪头回正会转过头一点点再摆回来；落灰抖掉带一下余震；连状态色都是渐变过去的
- **更多小动作**：在它身上左右来回滑 = 摸头（月牙眼 + 脸红 + 冒爱心）；停在上面不动 = 歪头好奇；在它面前快速左右甩鼠标 = 跟着扫视到晕；很久没人理 = 身上落灰，一靠近就抖掉；快睡着前会先打个哈欠
- **面板**：逐题显示答案和一句解析，支持单题重填、单题复制、整页诊断

## 安装

1. 下载或克隆本仓库，找到 `quiz-copilot` 文件夹
2. Edge 打开 `edge://extensions`（Chrome 用 `chrome://extensions`）
3. 打开右上角（Edge 是左下角）的 **开发者模式**
4. 点 **加载已解压的扩展程序**，选中 `quiz-copilot` 文件夹
5. 点工具栏上的图标，填 API Key，点 **测试连接**

Key 在 [platform.deepseek.com](https://platform.deepseek.com/api_keys) 申请，充 10 块钱能答很多卷。

**更新代码后必须先在扩展页点 ↻ 重新加载，再刷新网页** —— 只按 F5 页面里跑的仍是旧脚本。

## 使用

打开答题页，右下角会出现小机器人。

| 操作 | 效果 |
|---|---|
| 点机器人 | 读题 → 作答 →（自动填开着时）写进页面 |
| 点气泡 | 打开面板看逐题答案和解析 |
| 右键机器人 | 菜单：换皮肤 / 番茄钟 / 划词解释 / 自动填 / 隐藏 |
| 在它身上左右滑 | 摸头（不会触发解题） |
| 停在它身上不动 | 歪头好奇 |
| 选中网页文字 | 旁边冒「解释这段」 |
| 按住拖动 | 拖到别处，位置会记住 |
| `Alt+Shift+Q` | 同「点机器人」 |
| `Alt+Q` | 开合面板 |

「自动填」开关在面板上、设置页和右键菜单里都有：开着点一下就直接写入；关掉只出答案，点气泡看详情。

单击是**锁死给解题**的，所以别的能力都挂在右键、悬停、选中、长按这些不冲突的通道上——这也是为什么加功能不会把「点一下就解题」弄坏。

读不到题时，先在面板里点 **诊断**，它会说清楚页面类型、有几个输入框、每个为什么被排除。

## 支持的题型

| 题型 | 识别依据 | 能否填入 |
|---|---|---|
| 单选 / 多选 | radio / checkbox 分组（兼容 Moodle 每个选项独立 name） | 能 |
| 判断 | 两个选项且是「正确 / 错误」这类 | 能 |
| 填空 | 文本框、数字框、contenteditable | 能，一题多空按顺序填 |
| 表格 / 矩阵 | 一张表里多行多列都是输入框 | 能，按行从左到右 |
| 匹配 | 左右两列，右列是下拉框 | 能，依赖左列文字或图片文件名 |
| 简答 / 论述 | 大文本框 | 不处理，主动避开 |

## 已知限制

- **跨域 iframe 读不到**，这是浏览器安全策略，任何扩展都一样；把题目页单独开一个标签
- **纯图文的空位**（画了横线但没有真输入框）能识别、能给答案，但填不进去
- **图片匹配题**只能靠 `alt`、`title` 或文件名推断，图名是 `image1.png` 这种就没辙
- **个人信息类题目**（作息、收入、证件号）模型给不出答案时会留空；如果它一边说「不知道」一边猜了个数字，插件会把这个数字丢掉，不会替你填

## 隐私

- API Key 只存在浏览器本地（`chrome.storage.sync`），不经过本项目的任何服务器
- 只有题目文本会发给你自己配置的模型接口
- 插件不收集、不上报任何使用数据

## 项目结构

```
quiz-copilot/
  manifest.json          MV3 清单
  background.js          调用模型、解析返回、快捷键转发
  popup.html/js          设置页
  content/
    00-core.js           常量、DOM 工具、共享状态
    10-choice.js         选择题提取
    15-text.js           纯文本题目解析
    20-blank.js          填空 + 表格题提取
    30-match.js          下拉匹配题
    40-extract.js        统一入口 + 诊断
    45-solve.js          拼提示词、发请求
    50-answer.js         答案匹配与回填
    60-css.js            面板样式
    70-panel.js          面板渲染与交互
    80-mascot.js         小机器人（表情、拖拽、摸头、落灰）
    85-menu.js           右键菜单
    86-pomo.js           番茄钟
    87-selection.js      划词解释
    90-main.js           一键流程、消息路由
```

外加三个可直接打开的单页：

- `安装说明.html` —— 图文安装与排错
- `本地测试卷.html` —— 六种题型 + 三个干扰项，用来验证插件本身
- `机器人预览.html` —— 表情图鉴 + 可拖动的真身

## 开发

零构建、零依赖。content script 按 manifest 里的数组顺序加载，共享 `window.__QC`（在扩展的隔离环境里，网页看不到）。

改完代码在扩展页点 ↻，刷新页面即可。

## 分享给别人

这个扩展没有上架商店，安装包就是一个文件夹。三种方式：

**1. 发压缩包（推荐）**

打包命令（Windows PowerShell，在仓库根目录执行）：

```powershell
Compress-Archive -Path quiz-copilot, 安装说明.html, 本地测试卷.html `
                 -DestinationPath dist\quiz-copilot.zip
```

对方解压后，双击 `安装说明.html`，照第 1 步加载 `quiz-copilot` 文件夹即可。
**API Key 不能随包发**——Key 跟账号走，对方得自己申请。

**2. 给仓库权限**

私有仓库在 Settings → Collaborators 里加对方 GitHub 用户名；要完全公开则 Settings → Danger Zone → Change visibility。
注意公开后提交历史里的作者邮箱也会一起公开。

**3. 上架商店**

Edge 加载项商店开发者账号免费，Chrome 应用商店一次性 5 美元。但「自动替人答题」这类用途审核风险很高，很可能被拒。
